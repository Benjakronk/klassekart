# Legacy — Klassekartograf v1

This is the original version of the app (p5.js canvas, single class, PDF export),
kept for reference. It is self-contained: open `legacy/index.html` to run it.

The current app (v2) lives in the project root:
- `index.html`, `klassekart.css`, `js/klassekart.js`

v2 is a ground-up rebuild: touch-first DOM (no canvas), smart rule-based
auto-arrange, multi-class management, history, present mode, and PDF/PNG/print export.
